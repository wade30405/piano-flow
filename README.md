# Piano Flow｜琴鍵數字練習

不看五線譜，照著琴鍵編號彈。

**線上打開：** https://wade30405.github.io/piano-flow/

## 這是什麼

把鋼琴譜換算成 88 鍵電鋼琴的**白鍵編號**（白鍵 1–52，中央 C 是 24 號），
一小節一小節照著數字按就能彈。黑鍵在琴上沒有印數字，所以標成
「夾住它的那兩個白鍵」，例如 `32–33`。

每首曲子有三種難度：

| 版本 | 說明 |
|------|------|
| 入門 | 整首移調成全白鍵，旋律的八度加厚壓成單音，一次只按一個鍵 |
| 只用白鍵 | 整首移調成全白鍵，保留原本的八度雙音 |
| 原調 | 照原譜的調，會用到黑鍵 |

移調不改變任何音程關係，聽起來是同一首歌，只是整體高低不同。

## 功能

- 全曲小節目錄，每格直接列出要按的琴鍵編號
- 逐小節跟彈，左右手可分開練
- 鍵盤只顯示該小節用到的音域，不必左右滑動
  （彈琴時雙手在琴上，沒有手能滑螢幕）
- 內建發聲，可單音試聽或整小節播放

## 關於曲譜

這個線上版**不含曲譜掃描圖**，只有從樂譜算出來的練習資料（琴鍵編號與音高）。
樂譜本身有版權，請自行取得。

## 離線使用

整個網站就是一個 HTML 檔，沒有任何外部相依。
把 `index.html` 存到電腦上雙擊即可離線使用。
